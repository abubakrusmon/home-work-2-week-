📌 About Project

Britlex is a responsive landing page for an online language learning platform.
The website helps users explore language learning skills, pricing plans, and online education opportunities in a modern and clean interface.

🚀 Features
Responsive Design
Modern UI Layout
Skills Section
Pricing Cards
Contact Form
Mobile / Tablet / Desktop Support
Built with Tailwind CSS
🛠 Technologies Used
HTML5
Tailwind CSS
Flexbox
CSS Grid
📱 Responsive Breakpoints

The project is optimized for:

Mobile — 320px
Small Devices — 575px
Tablet — 767px
Laptop — 992px
Desktop — 1200px+
